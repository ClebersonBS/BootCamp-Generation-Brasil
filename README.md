Atividade: Vetores - Generation Brasil

Este repositório contém a resolução da atividade prática sobre Vetores(Arrays), desenvolvida durante a sessão de Lógica de Programação (INTRO-CS4) do bootcamp da Generation Brasil.

- Objetivo do Exercício
O código aqui presente tem como objetivo demonstrar a manipulação de estruturas de dados unidimensionais (vetores), incluindo a leitura de dados inseridos pelo utilizador e a realização de operações matemáticas e lógicas, tais como:
* Identificar elementos em índices ímpares;
* Identificar elementos que são números pares;
* Calcular a soma e a média de todos os elementos.

- Tecnologia e Ferramentas
* Linguagem:Portugol (pseudocódigo)
* Ambiente de Desenvolvimento: Portugol Studio
